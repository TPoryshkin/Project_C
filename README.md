Цифрова бібліотека - Система управління бібліотечними фондами
Опис проекту
Цифрова бібліотека - це програмна система для управління електронними бібліотечними фондами, розроблена на мові C#. Система дозволяє організовувати, зберігати та надавати доступ до різноманітних видань у цифровому форматі, автоматизувати бібліотечні процеси та забезпечувати ефективний пошук інформації.

Структура проекту
Основні класи
DigitalLibrary
Центральний клас системи, що містить колекції всіх елементів бібліотеки. Реалізує інтерфейс IEnumerable<Book> для ітерації по книгах.

LibraryItem (абстрактний клас)
Базовий клас для всіх бібліотечних матеріалів. Визначає спільні властивості та методи для книг та журналів.

Book та Magazine
Конкретні реалізації бібліотечних елементів. Клас Book реалізує інтерфейси IPrintable, ICloneable, IComparable<Book>.

LibraryUser
Клас для представлення користувачів бібліотеки з можливістю взяття та повернення книг.

Author та BookDetails
Допоміжні класи для зберігання додаткової інформації про книги та авторів.

Інтерфейси
IPrintable
Визначає контракт для друкованих об'єктів з методом Print().

ICloneable, IComparable, IEnumerable
Стандартні інтерфейси .NET для клонування, порівняння та ітерації.

Делегати та події
Вбудовані делегати .NET
Action<T> - для методів без повернення значення

Func<T, TResult> - для методів з поверненням значення

Predicate<T> - для методів-предикатів (фільтрація)

Власний делегат
LibraryEventHandler - делегат для подій бібліотеки

Події системи
BookAddedEvent - викликається при додаванні нової книги

LibraryNotification - загальні сповіщення бібліотеки

BookBorrowedEvent - користувач взяв книгу

BookReturnedEvent - користувач повернув книгу
